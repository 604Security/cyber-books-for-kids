# Contributing

Thanks for helping kids learn about staying safe online!

## Adding a book

1. The book must be published and available to buy or borrow.
2. It must be aimed at kids or teens (roughly ages 3–17).
3. It must cover online safety, privacy, cybersecurity, hacking, or codes and ciphers.
4. Add it to the right age section, in the table format used there.
5. Open a pull request with one book per PR and a short note on why it belongs.

## Removing or fixing an entry

Open an issue or PR explaining what's wrong (outdated, wrong age range, broken link).
